# CostMin-Meal-Planner-and-Tracker-with-Scan
CostMin finds the cheapest (or highest-quality) daily meal plan that hits your calorie, protein, fat, carb, fiber, and micronutrient targets. It uses a two-phase simplex solver, DIAAS-adjusted effective protein, three budget modes, a 160+ food database, barcode lookup via Open Food Facts, a daily food + water + weight ledger, and editable local prices. Runs entirely in the browser.
